Every suggestion shows its receipts:   ✓ HouseE2+2 BPM8A  — same genre, same energy tier, 2 BPM up, key 8A.
OPTIONAL
The energy tiers are my own custom system — totally optional. I tag a track's energy right in its genre field — 1 - House2 - House3 - House — where 1 / 2 / 3 = low / mid / high. The key idea: energy is relative to each genre. A 1 - House and a 1 - Nu Funk aren't the same vibe — each just sits at the low end for its own genre. Smart Playlist Creator reads that, keeps suggestions within ±1 tier (no jarring 1→3 jumps), and lets you EASE / BUILD across them. Don't tag energy? Nothing breaks — it leans harder on genre, BPM, and key. Roll your own scale, or skip it.

🎚️ Intent — lead the floor

Tell it where you're taking the energy. Not slavish to Camelot — built for instinct.

EASE −KEEPBUILD +

EASE cools it down · KEEP holds the vibe · BUILD lifts it.

⏱️ BPM window + ½ / double-time

Set your pitch range — start ±6%, type bigger when you're feeling brave. A 124 won't get suggested into a 112.

Flip on ½ / double-time and it'll find the 140 DnB that drops into your 70 hip-hop.

03 Build & Send to Rekordbox

📦 Drop tracks into the Set Builder, then export 3 ways

→ RBDirect to rekordbox. Writes the playlist straight into your library — no import. Quit rekordbox first; it backs up your library automatically before it touches anything.
⬇ XMLrekordbox XML file. The safe classic — point rekordbox at it (Prefs → Advanced → Database → rekordbox xml) and drag the playlist in. Carries BPM, key & rating.
NMLTraktor NML for the Traktor heads.

⚠ Missing files show red. If a track lives on an unplugged drive or moved, it won't link — plug in / fix the path. It skips dead files and flags them.

04 Quick Start

  1. Run ./launch.sh → open localhost:5001
  2. First run pops the config — point it at your Traktor COLLECTION.nml and Mixed In Key "All Playlists" JSON (hit BROWSE…)
  3. Click a track → read the Mix Suggestions → double-click to add to your set
  4. Name the set → hit an export → drop it in the booth
